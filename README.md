# AAI Protocol (Archived)

This repository previously contained the AAI Protocol specification. The protocol has been deprecated — its core ideas (progressive disclosure, app-level MCP gateway) are now implemented directly in **aai-gateway**.

## → Go to [aai-gateway](https://github.com/gybob/aai-gateway)

**aai-gateway** is the active project that provides:

- One MCP connection, many apps
- Progressive disclosure at the app level
- Support for MCP servers, CLI tools, skills, and more

All future development happens there.
